# FaceMemory — reconhecimento simultâneo de rostos

Atualização: a câmera agora tenta detectar e comparar todos os rostos visíveis no mesmo quadro, permitindo identificar duas pessoas ao mesmo tempo (e mais de duas, se a câmera e as condições permitirem). Cada pessoa precisa estar cadastrada previamente.

## Como executar
1. Extraia o ZIP.
2. Abra a pasta no VS Code e use a extensão Live Server.
3. Permita acesso à câmera e cadastre as pessoas com fotos nítidas.
4. Coloque as pessoas no enquadramento e clique em “Reconhecer agora”.

É necessária conexão com a internet para carregar a biblioteca e os modelos faciais. O resultado depende da iluminação, posição, resolução e dos perfis cadastrados. Não há garantia de reconhecimento em qualquer ângulo. Use somente com consentimento; os dados permanecem no armazenamento local do navegador.
